# RPT fraud-risk study — public demo site

Static site generated by `scripts/export_site.py` in the TrainingPipeline repository from the research outputs (run `outputs/full_all`, battery `design_tests_v2/main31`, 2026-10-10 14:55 UTC). Nothing here is hand-edited; regenerate after any re-run.

The 'Run the model' page loads JSON with fetch(), which browsers block for file:// addresses: open the GitHub Pages URL or serve the folder locally (`python -m http.server 8080`). `node tools/verify.mjs` re-runs the browser computation and reports the largest difference from the recorded numbers.

Only public SEC filing excerpts and the coder's evidence sentences are included. Design tests are the primary results; the fitted score is exploratory; every result is an association that identifies fraud already under way, not a prediction.
