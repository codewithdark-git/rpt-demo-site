# RPT Signals

Static site of the study *Related-party transactions and fraud risk* (a matched case-control study of SEC enforcement cases), generated 2026-10-17 09:58 UTC. Nothing here is hand-edited.

The 'Run the model' page loads JSON with fetch(), which browsers block for file:// addresses: open the GitHub Pages URL or serve the folder locally (`python -m http.server 8080`). `node tools/verify.mjs` re-runs the browser computation and reports the largest difference from the recorded numbers.

Only public SEC filing excerpts and the coder's evidence sentences are included. Results are associations observed before public disclosure, not predictions. The underlying datasets and code will be released when the research is published.
