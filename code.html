Reproduce every table

  1. Unzip DatePreparedPipeline; pip install -r requirements.txt; set SEC_USER_AGENT; run python run_pipeline.py --cases-csv cases_core.csv --output-dir data_core --start-year 2004 --end-year 2024, then scripts/eightk_items.py, scripts/fetch_all_proxies.py, scripts/tenka_restatements.py.
  2. Unzip TrainingPipeline next to it; python main.py build --config rpt_panel.full_all.json --skip-download.
  3. python scripts/design_tests_v2.py --config rpt_panel.full_all.json --name main31; python scripts/power_simulation.py.
  4. python main.py model|stress|mediate|explain|report --config rpt_panel.full_all.json for the exploratory model.
  5. python scripts/export_site.py regenerates this site, the workbook and the tables.

Data statement

All inputs are public SEC EDGAR data. The site ships section excerpts of 10-K and DEF 14A filings capped at 3000 characters, the coder's evidence sentences, XBRL values with tags and accession numbers, and the derived numbers. The full corpus (about 3 GB) and the coded tables stay with the research repositories.

Generated 2026-10-10 16:13 UTC from run outputs/full_all, battery design_tests_v2/main31 (TrainingPipeline dca7c38, DatePreparedPipeline f754840). Design tests are the primary results; the fitted score is exploratory; results are associations observed in the five years before public disclosure, not predictions. Only public SEC filing excerpts are shown.
