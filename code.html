Fitted model files

The exploratory models are scikit-learn pipelines saved with pickle by rpt_panel/modelling.py::save_model (dictionary with pipeline, text_model, features, threshold). They were fitted on the 30 matched sets available at training time (833 firm-years). Load them only with the project's own rpt_panel.predict.load_model.

How to reproduce every table

  1. Unzip DatePreparedPipeline; pip install -r requirements.txt; set SEC_USER_AGENT="Your name you@university.edu"; run python run_pipeline.py --cases-csv cases_core.csv --output-dir data_core --start-year 2004 --end-year 2024 (about 3.5 hours; downloads the public filings), then python scripts/eightk_items.py, python scripts/fetch_all_proxies.py and python scripts/tenka_restatements.py.
  2. Unzip TrainingPipeline next to it; pip install -r requirements.txt; python main.py build --config rpt_panel.full_all.json --skip-download builds the firm-year panel and codes the characteristics (about 25 minutes).
  3. python scripts/design_tests_v2.py --config rpt_panel.full_all.json --name main31 runs the design battery (the primary results); python scripts/power_simulation.py restates power.
  4. python main.py model --config rpt_panel.full_all.json then stress, mediate, explain, report fit and validate the exploratory model (about 3 hours).
  5. python scripts/make_thesis_chapters.py, make_review_response.py, make_companies_doc.py write the documents; python scripts/export_site.py regenerates this site.

Data statement

All inputs are public SEC EDGAR data (submissions API, Archives, XBRL company facts and frames, full-text search, enforcement releases). This site ships only section excerpts of 10-K and DEF 14A filings (capped at 3000 characters), the coder's evidence sentences, XBRL values with their tags and accession numbers, and the derived numbers. The complete downloaded corpus (about 3 GB) and the coded tables stay with the research repositories. No personal data beyond what the filings themselves disclose is included.

Site contract

Per-company JSON files live in data/companies/<CIK>.json; the global parameters (ranking distributions, logit coefficients, thresholds, metrics) in data/global.json; the selector index in data/index.json. tools/verify.mjs re-runs the browser computation under Node and reports the largest difference from the recorded numbers.
